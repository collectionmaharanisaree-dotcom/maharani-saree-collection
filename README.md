# Maharani Saree Collection

A mobile-first, GitHub Pages-compatible fashion catalogue and WhatsApp ordering website for **Maharani Saree Collection**, Derni Bazar, Saran, Bihar.

## Files

- `index.html` — semantic page structure, SEO metadata, offers, location map, QR area, cart and checkout dialogs.
- `styles.css` — responsive premium fashion-store styling.
- `script.js` — editable product catalogue, search/filter, product details, persistent cart and WhatsApp order generation.
- `favicon.svg` — lightweight M logo favicon.

## Updating products

Open `script.js` and edit the `products` array. Each product has `name`, `category`, `price`, `mrp`, `image`, and `description`. The current entries are explicitly **sample catalogue entries**: replace their photos and prices with confirmed stock data before publishing them as real products. Add any of these supported categories as needed: Saree, Lehnga, Suit, Kurti, Palazo, Leggings, Straight Pant, Kids Clothes, Jeans, Shorts, T-Shirts and Under Garments.
